# 문제 시작

대상: `$ARGUMENTS` (비어 있으면 `./kata list`를 보여주고 무엇을 풀지 묻는다)

1. `./kata start $ARGUMENTS`를 실행한다. 이미 진행 중이면 그 결과(현재 단계, 경과 시간)를 그대로 전한다.
2. 문제 폴더의 `README.md`에서 **제한 시간과 평가 포인트**만 3~5줄로 요약한다.
3. 현재 단계 문서 경로를 알려주고 **사용자가 직접 읽게** 한다. 요구사항을 대신 요약하거나 해설하지 않는다.
4. 다음 행동을 안내하고 멈춘다.
   - "5분 동안 `NOTES.md`(트랙 B·C는 각 spec의 열린 질문/plan.md)에 질문 목록을 적어 보세요."
   - "질문이 준비되면 `/interviewer`로 물어보세요."
   - "구현을 시작할 때 `Stage{N}Test`의 잠금을 풀고, 끝나면 `/next-stage $ARGUMENTS`."

금지: 설계 방향, 자료구조, 주의할 엣지 케이스를 먼저 말하지 않는다.
