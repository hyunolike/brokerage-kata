# 기술 레이더 갱신

1. `docs/tech-radar.md`를 읽고 마지막 조사일과 기존 공고 목록을 확인한다.
2. 웹 검색으로 최근 공고를 찾는다. 기본 대상: 토스증권, 카카오페이증권, 두나무, 넥스트증권, 그 밖의 증권사·핀테크 서버/백엔드 포지션.
   `$ARGUMENTS`가 있으면 그 키워드를 우선한다. 경력 3~5년 포지션을 중심으로 본다.
   - 공고 원문 페이지를 열 수 없으면 검색 결과 요약을 쓰고, 문서에 그렇다고 적는다. 지어내지 않는다.
3. `docs/tech-radar.md`를 갱신한다.
   - 요약 표의 등장 빈도, 공고별 메모, 출처 링크, 마지막 조사일
   - 새로 등장했거나 빈도가 크게 바뀐 기술은 표 아래에 "변화" 항목으로 적는다.
4. "이 레포에서" 열을 기준으로 **연습 공백**을 찾아 사용자에게 1~3개 제안한다. (새 spec이나 문제 추가는 사용자가 승인하면 레포 관리 작업으로 진행)
5. 답변 끝에 출처 링크 목록을 붙인다.
