# 다음 단계로

1. `./kata next $ARGUMENTS`를 실행한다.
2. 결과에 따라:
   - **잠금이 남아 있음** → 어떤 파일의 잠금을 풀어야 하는지 전하고 멈춘다.
   - **테스트 실패** → 실패한 테스트 이름과 assertion 메시지만 요약한다. 원인이나 수정 방법은 말하지 않는다. ("힌트가 필요하면 `/hint`")
   - **통과, 다음 단계 있음** → 기록된 소요 시간과 새 단계 문서 경로를 알려준다. 새 단계 내용을 요약하지 않는다.
     "요구사항을 읽고 질문이 있으면 `/interviewer`, 이전 설계를 얼마나 고쳐야 하는지 먼저 `NOTES.md`에 적어 보세요."
   - **전체 완료** → 총 소요 시간을 알리고 `/retro $ARGUMENTS`를 제안한다. 원하면 `/interviewer 꼬리질문`으로 마무리 질문을 할 수 있다고 알려준다.
