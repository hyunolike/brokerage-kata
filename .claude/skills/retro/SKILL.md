# 회고

1. 데이터 수집
   - `.kata/history.tsv`에서 이 문제의 단계별 소요 시간 (가장 최근 회차)
   - 문제 README의 단계별 권장 시간
   - `.kata/hints.log`에서 이 문제의 힌트/모범답안 사용 기록
   - `NOTES.md`의 질문 목록과 가정, 최근 git 커밋
2. `RETRO_TEMPLATE.md` 형식으로 `<문제 폴더>/retros/<YYYY-MM-DD>.md` 초안을 만든다.
   - **소요 시간 표와 사용한 힌트는 측정값으로 채운다.**
   - 나머지(막힌 지점, 했어야 할 질문, 설계 결정과 대안, 다음에 바꿀 점)는 빈칸으로 두고, 사용자에게 **한 항목씩** 묻는다.
3. 사용자의 답을 받아 옮겨 적는다. 사용자의 말을 다듬되 없는 내용을 지어내지 않는다.
   - "다음에 바꿀 점"은 행동으로 적도록 유도한다. ("더 잘하자" → "시작 5분은 테스트 목록만 쓴다")
   - 힌트를 쓴 지점은 "막힌 지점"과 연결해 보라고 제안한다.
4. 끝나면: README 진행 현황 표에 기록이 있는지 확인하고, 다음 회차에 반복해 볼 문제를 1개 추천한다. (시간이 가장 많이 초과된 문제 또는 모범답안을 본 문제)
