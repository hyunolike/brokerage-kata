# Spec 001. 계좌와 입금

## 배경 / 목적

모의 투자 서비스 사용자는 계좌를 만들고 돈을 넣어야 주문할 수 있다.

## 사용자 시나리오

1. 사용자가 이름으로 계좌를 개설한다.
2. 계좌에 돈을 입금한다.
3. 현재 예수금과 주문 가능 금액을 확인한다.

## 기능 요구사항

- **FR-001-1** 계좌 개설: 소유자 이름(1~20자)으로 계좌를 만들고 계좌 식별자를 발급한다.
- **FR-001-2** 입금: 1원 이상, 1회 최대 1억 원까지 입금할 수 있다.
- **FR-001-3** 잔고 조회: 다음 세 값을 조회할 수 있다.
  - 예수금 총액 = 주문 가능 금액 + 주문에 묶인 금액
  - 주문 가능 금액
  - 주문에 묶인 금액 (002에서 사용, 지금은 항상 0)
- **FR-001-4** 입금 내역을 시간 역순으로 조회할 수 있다.

## 수용 기준

- **AC-001-1** Given 이름 "홍길동" When 계좌 개설 Then 계좌 식별자가 발급되고 잔고는 모두 0이다.
- **AC-001-2** Given 이름이 비어 있거나 20자를 넘음 When 계좌 개설 Then 요청 검증 실패.
- **AC-001-3** Given 잔고 0인 계좌 When 100,000원 입금 Then 예수금 총액·주문 가능 금액이 100,000원이다.
- **AC-001-4** Given 계좌 When 0원 또는 1억 원 초과 입금 Then 요청 검증 실패, 잔고 변화 없음.
- **AC-001-5** Given 존재하지 않는 계좌 When 입금 또는 조회 Then "계좌 없음" 실패.
- **AC-001-6** Given 30,000원, 50,000원 순서로 입금 When 입금 내역 조회 Then 50,000원이 먼저 나온다.

## 범위 밖

- 인증/인가 (요청에 계좌 식별자를 그대로 받는다)
- 출금, 계좌 해지
