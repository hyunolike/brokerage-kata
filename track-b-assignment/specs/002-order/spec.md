# Spec 002. 주문 생성 / 취소 / 조회

## 배경 / 목적

사용자는 예수금 안에서 주식 **매수** 주문을 내고, 체결 전에는 취소할 수 있다.
(체결 엔진은 이 과제의 범위 밖이다. 체결은 테스트용 API로 흉내 낸다)

## 기능 요구사항

- **FR-002-1** 주문 생성: `계좌, 종목코드(6자리 숫자), 수량(1 이상), 가격(1 이상, 호가 단위 준수)`로 **지정가 매수** 주문을 만든다.
  - 호가 단위는 트랙 A p1 stage-1의 표를 따른다.
  - 주문 금액(가격 × 수량)만큼 주문 가능 금액이 **묶인 금액**으로 옮겨간다.
  - 주문 가능 금액이 부족하면 거부한다.
- **FR-002-2** 주문 상태: `접수(RECEIVED) → 체결(FILLED)` 또는 `접수 → 취소(CANCELED)`.
- **FR-002-3** 주문 취소: 접수 상태에서만 가능. 묶인 금액이 주문 가능 금액으로 돌아온다.
- **FR-002-4** 주문 조회: 단건 조회, 계좌별 목록 조회(상태 필터, 최신순, 페이징).
- **FR-002-5** 체결(테스트용): 접수 상태 주문을 전량 체결 처리한다. 묶인 금액이 확정 차감된다.

## 수용 기준

- **AC-002-1** Given 주문 가능 100,000원 When 10주 × 7,000원 매수 Then 주문 접수, 주문 가능 30,000 / 묶인 금액 70,000.
- **AC-002-2** Given 주문 가능 100,000원 When 20주 × 7,000원 매수 Then "잔고 부족" 실패, 잔고 변화 없음.
- **AC-002-3** Given 가격 71,050원 When 매수 Then "호가 단위 위반" 실패.
- **AC-002-4** Given 접수 주문(70,000원) When 취소 Then 상태 CANCELED, 주문 가능 100,000 / 묶인 금액 0.
- **AC-002-5** Given 취소 또는 체결된 주문 When 취소 Then "취소 불가 상태" 실패.
- **AC-002-6** Given 접수 주문 When 체결 Then 상태 FILLED, 예수금 총액이 주문 금액만큼 줄어든다.
- **AC-002-7** Given 주문 3건(접수 2, 취소 1) When 상태=RECEIVED 로 목록 조회 Then 2건이 최신순으로 나온다.
- **AC-002-8** Given 다른 계좌의 주문 When 조회/취소 Then 실패한다.

## 범위 밖

- 매도 주문, 보유 종목(잔고) — 시간이 남으면 새 spec으로 추가
- 시장가 주문, 부분 체결, 정정
- 실제 종목 마스터 (종목코드 형식만 검증)
