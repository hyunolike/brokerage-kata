# Spec 006. 원클릭 실행

## 배경 / 목적

평가자는 레포를 받아 **명령 한 줄**로 실행해 본다.

## 기능 요구사항

- **FR-006-1** `track-b-assignment` 디렉터리에서 `docker compose up` 한 번으로 애플리케이션, MySQL, Redis가 뜬다.
- **FR-006-2** 애플리케이션은 DB와 Redis가 준비된 뒤에 시작한다.
- **FR-006-3** 스키마는 자동으로 준비된다. (방식은 plan/ADR에서 결정)
- **FR-006-4** README에 실행 방법, 확인용 curl 예시가 있다.

## 수용 기준

- **AC-006-1** 빈 환경에서 `docker compose up --build` 후 계좌 개설 → 입금 → 주문 → 조회 curl 시나리오가 성공한다.
- **AC-006-2** `docker compose down -v` 후 다시 올려도 동일하게 동작한다.
- **AC-006-3** 이미지 크기와 빌드 시간을 줄이기 위해 멀티 스테이지 빌드를 사용한다.

## 범위 밖

- 운영 배포, CI/CD
