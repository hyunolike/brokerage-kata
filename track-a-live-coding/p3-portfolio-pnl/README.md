# p3. 잔고와 손익 계산 (Portfolio PnL)

> 금액 계산 정확성 + 엣지 케이스 · 제한 시간 **60분** (4단계)

## 배경

거래 내역(체결 목록)을 받아 **보유 수량, 평균 단가, 실현/평가 손익**을 계산한다.
단계가 진행되면 수수료·세금, 해외주식 환율까지 반영한다.
돈을 다루는 코드이므로 "1원이 어디서 새는가"를 끝까지 추적해야 한다.

## 단계 구성

| 단계 | 파일 | 권장 시간 |
|---|---|---|
| 1 | `stages/stage-1.md` | 15분 |
| 2 | `stages/stage-2.md` | 10분 |
| 3 | `stages/stage-3.md` | 15분 |
| 4 | `stages/stage-4.md` | 20분 |

> ⚠️ 현재 단계를 끝내기 전에는 다음 단계 파일과 다음 단계 테스트 파일을 열지 않는다.

## 평가 포인트

- **`BigDecimal` 사용** — `double` 금지. `new BigDecimal(double)` vs `BigDecimal.valueOf`, `equals` vs `compareTo`
- **반올림 정책** — 어디서 몇 자리로 무엇(HALF_UP, DOWN)을 쓰는지 한곳에서 관리하는가
- **엣지 케이스** — 전량 매도, 0주 보유 시 평균단가/수익률, 보유보다 많은 매도
- **금액 타입** — 원화(정수)와 외화(소수 2자리)를 섞지 않도록 타입으로 막았는가
- 계산 순서(먼저 곱하고 나중에 나누기)에 따른 오차를 설명할 수 있는가
