# Stage 1. 예수금 차감

## 요구사항

1. 계좌를 만들고 **입금**할 수 있다. 입금액은 1원 이상이다.
2. **주문**하면 주문 금액만큼 예수금이 차감된다. 주문은 `계좌ID, 주문ID, 주문 금액(원)`을 가진다.
3. 예수금이 부족하면 주문은 **거부**되고 예수금은 변하지 않는다.
4. 예수금을 조회할 수 있다.
5. 존재하지 않는 계좌에 대한 요청은 실패한다.

> 이번 단계는 단일 스레드만 고려한다.

## 입출력 예시

| # | 요청 | 결과 | 예수금 |
|---|---|---|---|
| 1 | 계좌 A 생성 | 성공 | 0 |
| 2 | A에 100,000 입금 | 성공 | 100,000 |
| 3 | A 주문 O1 30,000 | 성공 | 70,000 |
| 4 | A 주문 O2 80,000 | **거부** (예수금 부족) | 70,000 |
| 5 | A 주문 O3 70,000 | 성공 | 0 |
| 6 | 계좌 X 주문 O4 1,000 | **실패** (계좌 없음) | - |
