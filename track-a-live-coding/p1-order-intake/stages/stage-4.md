# Stage 4. 정정 / 취소

## 요구사항

### 취소
- 미체결 잔량 **전부**를 취소한다. (일부 수량만 취소하는 기능은 없다)
- 취소된 주문은 **CANCELED** 상태가 되며 종료 상태다.
- 부분 체결된 주문을 취소해도 **이미 체결된 수량과 평균 체결가는 유지**된다.

### 정정
- 지정가 주문의 **가격** 또는 **수량**을 정정할 수 있다.
  - 가격 정정: Stage 1의 가격 검증(호가 단위, 주문 한도)을 다시 적용한다. 한도 계산은 `새 가격 × 미체결 잔량`.
  - 수량 정정: **미체결 잔량을 줄이는 방향으로만** 가능하다. 잔량을 0으로 만드는 정정은 거부한다(취소를 사용).
- 시장가 주문은 정정할 수 없다.
- 정정 후에도 주문번호는 그대로 유지한다.

### 공통
- FILLED, CANCELED 상태의 주문은 정정/취소할 수 없다.
- 존재하지 않는 주문번호는 실패한다.

## 입출력 예시

주문 #1: LIMIT BUY `005930` 10주 @ 71,000

| # | 요청 | 결과 |
|---|---|---|
| 1 | 3주 @ 71,000 체결 | PARTIALLY_FILLED, 잔량 7 |
| 2 | 가격 71,500으로 정정 | 성공, 가격 71,500, 잔량 7 |
| 3 | 가격 71,550으로 정정 | 실패: 호가 단위 |
| 4 | 수량(잔량)을 5로 정정 | 성공, 주문 수량 8 (체결 3 + 잔량 5) |
| 5 | 수량(잔량)을 6으로 정정 | 실패: 잔량을 늘릴 수 없음 |
| 6 | 취소 | CANCELED, 누적 체결 3, 평균 체결가 71,000 유지 |
| 7 | 취소 | 실패: 이미 종료된 주문 |

## 보너스 (시간이 남으면)

실제 거래소는 정정 시 **새 주문번호**를 발급하고 원주문과 연결한다.
주문번호가 바뀌어야 한다면 지금 설계에서 어디를 고쳐야 하는지 말로 설명해 보라.
