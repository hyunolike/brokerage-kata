# Spec C003. 주문 내역과 취소

> 의존: 트랙 B spec 002 (주문 조회/취소)

## 기능 요구사항

- **FR-C003-1** 주문 목록: 최신순, 상태 뱃지(접수/체결/취소), 페이징 또는 더보기
- **FR-C003-2** 상태 필터
- **FR-C003-3** 접수 상태 주문만 취소 가능. 취소 전 확인.
- **FR-C003-4** 취소 성공 시 목록과 잔고를 함께 갱신한다.
- **FR-C003-5** 취소 실패(예: 이미 체결됨) 시 원래 상태로 되돌리고 이유를 보여준다.

## 수용 기준

- **AC-C003-1** 주문 3건 → 최신순 + 상태 뱃지
- **AC-C003-2** 필터 "접수" → 접수 주문만
- **AC-C003-3** 체결/취소 주문에는 취소 버튼 없음
- **AC-C003-4** 취소 확인 → 뱃지 "취소", 주문 가능 금액 증가
- **AC-C003-5** 서버가 "취소 불가" 응답 → 뱃지 원복, 사유 표시
