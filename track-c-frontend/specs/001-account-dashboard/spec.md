# Spec C001. 계좌 대시보드

> 의존: 트랙 B spec 001 (계좌와 입금) API 계약

## 배경 / 목적

사용자가 계좌를 만들고, 입금하고, 잔고를 한눈에 본다.

## 기능 요구사항

- **FR-C001-1** 계좌 개설 폼(소유자 이름)과 개설 결과 표시
- **FR-C001-2** 입금 폼. 금액이 비었거나 1원 미만이면 제출할 수 없다.
- **FR-C001-3** 잔고 카드: 예수금 총액, 주문 가능 금액, 묶인 금액을 원화 형식(`1,234,567원`)으로 표시
- **FR-C001-4** 잔고 로딩 / 실패(재시도 버튼) 상태 표시
- **FR-C001-5** 입금 내역 목록 (최신순)

## 수용 기준

- **AC-C001-1** `formatKrw(1234567)` → `1,234,567원`, `formatKrw(0)` → `0원`
- **AC-C001-2** Given 이름 입력 When 계좌 개설 Then 계좌 정보와 0원 잔고가 보인다.
- **AC-C001-3** Given 계좌 When 50,000원 입금 Then 잔고 카드가 50,000원으로 갱신된다.
- **AC-C001-4** Given 입금 금액이 비었거나 0 When 화면 Then 입금 버튼 비활성화.
- **AC-C001-5** Given 잔고 API 지연/실패 When 화면 Then 로딩 표시 / 에러 메시지와 재시도 버튼.

## 범위 밖

- 로그인, 여러 계좌 전환
