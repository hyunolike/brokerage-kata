# Spec C005. 백엔드 연동

> 의존: 트랙 B 전체 (특히 006 docker)

## 기능 요구사항

- **FR-C005-1** 개발 서버에서 트랙 B 백엔드로 프록시 연동 (`vite.config.ts`)
- **FR-C005-2** 목(mock) 데이터와 계약이 어긋나지 않게 한다. (예: 계약의 example을 목으로 재사용, openapi-typescript로 타입 생성)
- **FR-C005-3** (선택) 트랙 B `docker-compose.yml`에 `web` 서비스를 추가해 `docker compose up` 한 번으로 백엔드 + 프론트엔드가 뜬다.

## 수용 기준

- **AC-C005-1** 목 응답이 계약 스키마/예시와 일치한다.
- **AC-C005-2** 실제 백엔드에 붙여 계좌 개설 → 입금 → 주문 → 취소를 화면에서 끝까지 수행할 수 있다.
