# Spec C002. 주문 폼

> 의존: 트랙 B spec 002 (주문) API 계약, 트랙 A p1 stage-1 호가 단위 표

## 기능 요구사항

- **FR-C002-1** 입력: 종목코드, 수량, 가격 (지정가 매수)
- **FR-C002-2** 클라이언트 검증 — 종목코드 6자리 숫자, 수량 1 이상, 가격이 호가 단위에 맞음
  - 호가 단위가 맞지 않으면 **가장 가까운 아래/위 유효 가격**을 안내한다.
- **FR-C002-3** 예상 주문 금액(가격 × 수량)과 주문 가능 금액을 함께 보여준다. 초과하면 제출 불가.
- **FR-C002-4** 제출 중 중복 제출 방지. 서버 멱등 키(트랙 B spec 003)를 요청에 포함한다.
- **FR-C002-5** 주문 성공 시 폼 초기화, 잔고 갱신. 실패 시 입력값 유지 + 이유 표시.

## 수용 기준

- **AC-C002-1** 종목코드 `5930` 입력 → 형식 오류 메시지
- **AC-C002-2** 가격 71,050 → "71,000원 또는 71,100원으로 입력하세요" 류의 안내 (`tickSize` 순수 함수 단위 테스트 포함)
- **AC-C002-3** 주문 가능 100,000원, 20주 × 7,000원 → 주문 버튼 비활성화
- **AC-C002-4** 10주 × 7,000원 → 예상 주문 금액 70,000원 표시
- **AC-C002-5** 제출 후 응답 전 버튼 재클릭 → 요청 1번만 발생
- **AC-C002-6** 주문 성공 → 폼 초기화, 주문 가능 금액 갱신
