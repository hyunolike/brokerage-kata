# Spec C006. 실시간 주문 상태 (선택)

> 의존: 트랙 B spec 008 (실시간 푸시). 백엔드가 없으면 계약에 정의한 메시지로 가짜 서버를 만들어 개발한다.

## 배경 / 목적

주문이 체결·취소되면 새로고침 없이 주문 내역과 잔고가 바뀌어야 한다.
실시간 연결은 언제든 끊길 수 있으므로 **끊김, 재연결, 중복 메시지**를 다루는 것이 핵심이다.

## 기능 요구사항

- **FR-C006-1** 계좌 화면에 들어오면 실시간 채널에 연결하고, 떠나면 연결을 정리한다.
- **FR-C006-2** 주문 상태 메시지를 받으면 주문 내역(C003)과 잔고(C001)를 갱신한다.
- **FR-C006-3** 연결 상태(연결됨 / 재연결 중 / 끊김)를 사용자에게 보여준다.
- **FR-C006-4** 끊기면 **점점 늘어나는 간격**으로 재연결을 시도하고, 재연결 후 놓친 변경을 반영한다.
- **FR-C006-5** 같은 메시지를 두 번 받아도, 순서가 뒤바뀌어 와도 화면 상태가 틀어지지 않는다.

## 수용 기준

- **AC-C006-1** 체결 메시지 수신 → 해당 주문 뱃지가 "체결"로 바뀐다.
- **AC-C006-2** 연결 끊김 → "재연결 중" 표시, 재연결 간격이 늘어난다 (가짜 타이머로 검증).
- **AC-C006-3** 재연결 성공 → 끊긴 동안 바뀐 주문 상태가 반영된다.
- **AC-C006-4** 같은 메시지 2회 수신 → 화면 변화는 1번.
- **AC-C006-5** 화면을 떠나면 연결이 닫힌다 (메모리 누수 없음).
