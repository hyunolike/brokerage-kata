# Spec C004. 공통 에러 처리

> 의존: 트랙 B spec 004 (공통 응답 포맷, 에러 코드)

## 기능 요구사항

- **FR-C004-1** `api/client.ts`의 `request`가 공통 응답 포맷을 해석해 성공 데이터 또는 **타입이 있는 에러**를 돌려준다.
- **FR-C004-2** 에러 코드 → 사용자 메시지 매핑을 한곳에서 관리한다.
- **FR-C004-3** 검증 실패의 필드 오류를 해당 입력 아래에 표시한다.
- **FR-C004-4** 네트워크 오류, 타임아웃, 5xx는 공통 안내와 재시도를 제공한다.
- **FR-C004-5** 렌더링 예외는 에러 바운더리로 격리한다.

## 수용 기준

- **AC-C004-1** 실패 응답 → 에러 코드를 가진 에러 객체 (`request` 단위 테스트)
- **AC-C004-2** 잔고 부족 / 계좌 없음 / 취소 불가 → 각각 다른 사용자 메시지
- **AC-C004-3** 400 필드 오류 → 해당 필드 아래 메시지
- **AC-C004-4** fetch 실패 / 503 → 공통 안내 + 재시도
- **AC-C004-5** 하위 컴포넌트 예외 → 해당 영역만 대체 UI
